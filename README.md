# 🚀 4ª Fase SENAI

Repositório dedicado aos **estudos, projetos e atividades da 4ª fase** do curso de **Desenvolvimento de Sistemas - SENAI**.

Aqui estão reunidos os conteúdos desenvolvidos durante o trimestre, incluindo exercícios, desafios e projetos práticos voltados ao aprimoramento das habilidades em programação e desenvolvimento de software.

---

## 📚 Conteúdo

- 💻 Projetos desenvolvidos em aula
- 🧠 Exercícios de lógica e programação
- ⚙️ Práticas com novas tecnologias
- 🛠️ Testes, experimentos e desafios
- 📂 Atividades propostas durante a fase

---

## 🎯 Objetivo

Este repositório tem como finalidade acompanhar minha evolução ao longo da **4ª fase**, servindo como registro dos conhecimentos adquiridos e dos projetos desenvolvidos durante o curso.

---

## 🚀 Tecnologias Utilizadas

Ao longo desta fase poderão ser utilizadas tecnologias como:

- HTML5
- CSS3
- JavaScript
- Java
- Banco de Dados
- Git e GitHub
- Outras ferramentas abordadas em aula
